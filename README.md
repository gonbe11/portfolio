# 배고운 — 테크니컬 애니메이터

한국어 포트폴리오 사이트입니다.

## 사이트

https://gonbe11.github.io/portfolio/

## 수정 방법

- 대표 작업: `content.js`의 제목, 설명, 이미지 경로, 영상 링크, 담당 역할, 사용 도구, 작업 과정 수정
- 작업 공개: 해당 항목의 `ready`를 `true`로 변경
- 소개·연락처: `index.html` 수정
- 색상·레이아웃: `style.css` 수정

이미지는 이 저장소에 추가하고 `content.js`의 `image`에 상대 경로를 입력합니다. 영상은 `video`에 HTTPS 링크를 입력합니다. 비어 있는 상세 항목은 화면에 표시하지 않습니다.

빌드 과정 없이 정적 파일로 동작합니다. GitHub Pages는 `main` 브랜치의 루트 디렉터리에서 배포합니다.
